## Deskripsi Singkat

**AmbilCepat** adalah prototipe web fungsional yang dirancang untuk memodernisasi pengalaman pelacakan perbaikan servis. Proyek ini bertujuan untuk menunjukkan keahlian dalam pengembangan front-end modern, desain UI/UX yang bersih, dan arsitektur kode vanilla JavaScript yang terstruktur.

Proposisi nilai unik (USP) dari proyek ini adalah: *"Memberikan pengalaman pelacakan servis yang cepat, transparan, dan elegan kepada pelanggan, menghilangkan ketidakpastian dan membangun kepercayaan."*

## Fitur Utama

-   **Halaman Beranda Informatif:** Landing page yang menarik secara visual untuk memperkenalkan layanan.
-   **Sistem Pelacakan Servis:** Fungsi pencarian berdasarkan ID servis yang unik.
-   **Daftar Servis Interaktif:** Tampilan semua servis aktif dalam format grid yang rapi dan responsif.
-   **Halaman Detail Servis:** Tampilan mendalam yang mencakup:
    -   Informasi Umum (Nama item, status, teknisi).
    -   Timeline Progres Visual yang jelas.
    -   Rincian Biaya yang terperinci.
-   **Modal Konfirmasi Pengambilan:** Jendela interaktif untuk mengkonfirmasi pengambilan barang.
-   **Sistem Notifikasi:** Umpan balik instan untuk aksi pengguna (misalnya, pencarian gagal atau konfirmasi berhasil).
-   **Desain Sepenuhnya Responsif:** Pengalaman pengguna yang optimal di desktop, tablet, dan mobile.

## Tech Stack

-   **HTML5:** Struktur semantik dan modern.
-   **Tailwind CSS:** Framework utility-first untuk styling yang cepat dan responsif.
-   **JavaScript (Vanilla):** Logika front-end murni tanpa library atau framework untuk menunjukkan pemahaman fundamental.

## Cara Menjalankan

Proyek ini tidak memerlukan build step atau server. Cukup ikuti langkah-langkah berikut:
