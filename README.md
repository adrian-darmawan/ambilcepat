## ✨ Features
- **Desain Profesional:** UI/UX didesain ulang sepenuhnya mengikuti Design System yang ketat (Tipografi, 8pt Grid, Skema Warna).
- **Alur Otentikasi:** Alur masuk pengguna yang disimulasikan menggunakan nomor telepon dan verifikasi OTP.
- **Halaman Beranda (Katalog):** Halaman utama baru yang menampilkan katalog jenis layanan yang ditawarkan.
- **Halaman Status:** Halaman khusus untuk melacak status semua layanan aktif dengan fitur pencarian real-time.
- **Halaman Jadwal & Pengaturan:** Kerangka untuk halaman penjadwalan dan pengaturan.
- **Navigasi Bawah:** Navigasi utama yang persisten untuk pengalaman pengguna yang lebih baik di perangkat mobile.
- **Tampilan Detail Interaktif:** Halaman detail layanan dengan timeline progres visual dan modal konfirmasi pengambilan.
- **Data Realistis & Persisten:** Menggunakan data layanan yang lebih beragam dan menyimpan statusnya di Local Storage.

## 🛠️ Tech Stack
- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript
- **Data Management**: Local Storage
- **Deployment**: GitHub Pages
- **Design**: Mobile-first responsive design, 8pt Grid System

## 🏗️ Installation & Setup
1. Clone repository: `git clone https://github.com/adrian-darmawan/ambilcepat.git`
2. Open `index.html` in your web browser.
3. No build step or local server is required.

## 📋 Project Background
Versi 3 dari aplikasi ini merupakan implementasi dari "Rencana Peningkatan (Improvement Plan)" yang bertujuan untuk merombak total prototipe awal menjadi aplikasi yang matang secara visual dan fungsional, sesuai dengan visi desain profesional.
