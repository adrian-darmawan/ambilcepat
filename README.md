## ✨ Features
- Real-time service tracking
- Responsive design for all devices
- Interactive timeline progress
- Service pickup confirmation
- Phone-based authentication (simulated)
- Modern UI with smooth animations

## 🛠️ Tech Stack
- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript
- **Data Management**: Local Storage
- **Deployment**: GitHub Pages
- **Design**: Mobile-first responsive design

## 🏗️ Installation & Setup
1. Clone repository: `git clone https://github.com/adrian-darmawan/ambilcepat.git`
2. Open `index.html` in your web browser.
3. No build step or local server is required.

## 📋 Project Background
Based on an internship report at Daya Cipta Mandiri Computer (DCM), this web application addresses manual service tracking inefficiencies by providing:
- Digital service status transparency
- Remote accessibility for customers
- Streamlined pickup confirmation process

## 👨‍💻 Development Process
- **Sprint-based development** (6 sprints)
- **Mobile-first responsive design**
- **Component-based architecture** in vanilla JavaScript
- **Local data simulation** for demo purposes using Local Storage
